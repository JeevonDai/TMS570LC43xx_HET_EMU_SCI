======================================
TMS570LC4357 项目 Clangd 配置修复说明
======================================

【问题】
1. "Too many errors emitted, stopping now" - clangd 无法识别 TI 编译器的头文件和宏定义
2. "Invalid argument '-std=c99' not allowed with 'Objective-C++'" - .h 文件被错误识别为 Objective-C++

【已完成的修复】

1. ✅ 创建 .clangd 配置文件（项目根目录）
   - 强制使用 C 语言模式（-xc 选项），避免 .h 文件被识别为 C++ 或 Objective-C++
   - 配置了 ARM Cortex-R5 架构
   - 添加了 TI 编译器头文件路径：D:/ti/ccs1281/ccs/tools/compiler/ti-cgt-arm_20.2.7.LTS/include
   - 添加了项目包含路径：HALCoGen/include
   - 定义了关键宏：__TMS470__, __TI_ARM__, __TMS570LC43xx__ 等
   - 禁用了大量警告以减少误报

2. ✅ 创建 .vscode/c_cpp_properties.json
   - C/C++ 扩展的备用配置

3. ✅ 创建 .vscode/settings.json
   - 优化了 clangd 参数
   - 配置了 Makefile 工具路径

【使用步骤】

1. 重启 Clangd 语言服务器：
   - 按 Ctrl+Shift+P
   - 输入：clangd: Restart language server
   - 回车执行

2. 等待索引完成（几秒到几分钟）

3. 验证效果：
   - 打开 HALCoGen/source/HL_esm.c
   - 检查错误数量是否大幅减少
   - 测试代码跳转功能（Ctrl+点击函数名）

【如果问题仍然存在】

方法 A - 切换到 C/C++ 扩展：
  编辑 .vscode/settings.json，修改：
  "C_Cpp.intelliSenseEngine": "default"
  然后重启 VS Code

方法 B - 检查编译器路径：
  确认路径是否正确：D:/ti/ccs1281/ccs/tools/compiler/ti-cgt-arm_20.2.7.LTS
  如果不同，需要修改 .clangd 和 c_cpp_properties.json 中的路径

方法 C - 查看 clangd 日志：
  VS Code -> View -> Output -> 选择 "Clang Language Server"
  查看具体错误信息

【注意事项】

- TI 编译器和 Clang 之间存在差异，可能仍会有少量误报
- 只要 Debug 目录下的 makefile 能正常构建即可
- 配置文件使用 YAML 格式，注意缩进（使用空格，不用 Tab）

【配置文件列表】
- .clangd                          （主配置文件）
- .vscode/c_cpp_properties.json    （C/C++ 扩展配置）
- .vscode/settings.json            （VS Code 设置）
- CLANGD_CONFIG_README.md          （详细说明文档）

【技术支持】
如有问题，请查看 CLANGD_CONFIG_README.md 获取更详细的说明。
