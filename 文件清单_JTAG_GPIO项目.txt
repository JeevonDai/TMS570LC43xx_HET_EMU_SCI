七、编译配置
================================================================================

【CCS项目配置】

1. 添加源文件:
   Project Explorer → 右键项目 → Add Files
   └── 添加: HALCoGen/source/jtag_gpio.c

2. 包含路径:
   Project Properties → C/C++ Build → Settings → Include Options
   └── 添加: ${PROJECT_ROOT}/HALCoGen/include

3. 编译选项:
   └── 使用默认TI ARM编译器选项即可

【编译验证】
   ✅ 无错误
   ✅ 无警告（或仅有HALCoGen相关的标准警告）
   ✅ 可以成功生成.out文件

八、使用流程
================================================================================

【第一步：了解项目】
    1. 阅读 README.md 了解项目概况          (5分钟)
    2. 阅读 JTAG_GPIO_快速参考.md          (5分钟)

【第二步：硬件准备】
    1. 阅读 硬件连接图.txt                  (10分钟)
    2. 按照接线图连接两块芯片                (15分钟)
    3. 检查连接和供电                       (5分钟)

【第三步：软件集成】
    1. 添加 jtag_gpio.c 到CCS项目          (2分钟)
    2. 编译项目，确认无错误                 (2分钟)
    3. HL_sys_main.c 已集成测试代码        (无需修改)

【第四步：测试验证】
    1. 下载程序到主控芯片                   (1分钟)
    2. 连接串口，查看输出                   (2分钟)
    3. 确认能读取到目标芯片的IDCODE         (验证)

【第五步：深入开发】
    1. 阅读 JTAG_GPIO_使用说明.md          (30分钟)
    2. 参考 jtag_gpio_example.c            (按需)
    3. 开发自己的JTAG应用                   (根据需求)
